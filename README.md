# 🦘 雅思听力 1、4 部分填空基础词汇（1820词）· 听音盲写特训站

> 专为**“听说流利、看得懂但提笔忘字”**的雅思考生定制！基于王陆《雅思听力 807 单词升级版单词表》（全 18 页去重共 **1820 个高频核心词**），帮助你用最高效的**纯听音盲写 + 魔鬼纠错肌肉记忆法**彻底攻克雅思听力 Part 1 & Part 4 填空拼写关。

---

## ✨ 核心功能亮点

### 1. 🎧 纯听音盲写（澳洲口音 `en-AU` 优先）
* **强制遮挡英文拼写**：只给中文释义、所在页码与词长虚线提示，逼迫大脑直接调用“听觉 → 字母组合”本能。
* **纯正澳洲口音 + 慢速细听**：优先调度系统 `en-AU` 澳洲英语发音，支持 `Tab` 键零延迟重播、`0.6x` 慢速播放，并内置在线真人词典语音兜底，手机/电脑 100% 清晰发声。
* **复数考点防坑提示**：针对雅思听力常考的复数名词（如 `facilities`、`pounds`、`materials`），自动提示 `⚠️ 注意复数后缀 (-s)`。

### 2. 🔥 魔鬼纠错与肌肉记忆罚写
* **逐字母标红对比**：拼错任何一个字母或漏写复数 `-s`，立即将正确单词拆解为字母砖块，精准标红写错/漏掉的字母位置。
* **强制重读 + 当场盲打罚写**：拼错瞬间自动重读发音，并锁死下一题——必须当场重新敲对一遍（支持敲击时自动高斯模糊遮挡答案，逼迫靠瞬间记忆盲打）才能过关，同时自动收入**魔鬼错题本**。

### 3. 🎯 20 词一局 · 四大特训模式（5 分钟摸鱼神器）
* **🎲 全库随机突击（1820 词）**：从所有未掌握的词库中随机抽 20 个，一次拼对即归档剔除。
* **📘 前 6 页专项恶补（700 词）**：集中火力攻克最核心的前 6 页高频词。
* **💀 魔鬼错题本复仇**：专门抽取曾经拼错过的死穴词汇反复锤炼，直到一次盲写正确才销号。
* **📑 按页码范围自选（第 1~18 页）**：背到第几页就抽查第几页。

### 4. 🗓️ 每日打卡日历 & 📱💻 手机/电脑云端实时同步
* **可视化打卡月历**：自动统计**当前连续打卡天数**、**历史最高连续打卡天数**与**累计打卡天数**（每日满 20 词点亮 `🔥` 满额金标）。
* **跨设备云同步**：无需注册账号，只需在手机和电脑端输入相同的**同步暗号**，两端的已掌握词库、错题本和打卡日历即可自动无损合并。

## 🚀 如何使用？

1. **在线直接使用（GitHub Pages）**：
   * 打开本项目的 GitHub Pages 网址，即可在电脑或手机浏览器中直接开始特训。
   * 手机端点击浏览器菜单 **“添加到主屏幕”**，即可像原生 App 一样全屏运行。
2. **本地离线使用**：
   * 下载本仓库中的 [`index.html`](./index.html)，双击即可在任意浏览器中运行。
